# 画像配置ガイド

このフォルダに画像ファイルを配置すると、自動的にサイトに反映されます。
画像が無い状態でもサイトは動作します（プレースホルダーが表示されます）。

## フォルダ構成

```
public/images/
├── hero.jpg                      トップページのヒーロー画像
├── products/
│   └── {商品ID}.jpg              各商品の画像
├── journal/
│   └── {記事slug}.jpg            各記事のアイキャッチ
└── about/
    └── honsha.jpg                会社案内の画像
```

## 画像の作り方

`docs/image-prompts.md` を参照してください。AI画像生成ツール用の
プロンプト集が用意されています。

## 使い方

### 新しい商品画像を追加する

1. 画像を用意（推奨: 800×600px, JPG, 200KB以下）
2. 商品IDと同じファイル名で保存（例: `shokado-tsuru.jpg`）
3. `public/images/products/` に配置
4. サイトを再読み込み → 自動で表示される

### 画像を差し替える

同じファイル名で上書き保存するだけ。コード変更不要。

## 商品ID一覧

`lib/products.ts` の `id` フィールドを参照してください。
記事のslugは `lib/journal.ts` の `slug` フィールドです。
