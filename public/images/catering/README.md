# ケータリング用画像

ChatGPT で生成したLPモックアップから、以下の画像を切り出して配置してください。

## 必要な画像ファイル

| ファイル名 | 用途 | 推奨サイズ | 切り出し場所 |
|---|---|---|---|
| `hero.jpg` | トップページのヒーロー画像 | 800×600px (4/3) | Page 1 左上の料理テーブル写真 |
| `course-casual.jpg` | カジュアルコースのお料理 | 640×480px (4/3) | Page 2 カジュアル欄の料理写真 |
| `course-standard.jpg` | スタンダードコースのお料理 | 640×480px (4/3) | Page 2 スタンダード欄の料理写真 |
| `course-premium.jpg` | プレミアムコースのお料理 | 640×480px (4/3) | Page 2 プレミアム欄の料理写真 |
| `hiromi-building.jpg` | 日本料理 広美の外観 | 400×400px (1/1) | Page 1 フッター / 各ページフッター |

## 切り出し方

ご提供いただいたLPモックアップ画像から、**画像編集ソフト（Windows フォト、Photoshop、GIMP 等）** で以下の手順：

1. LPモックアップ全体画像を開く
2. 必要な画像部分を矩形で選択
3. 指定サイズでトリミング
4. JPEG品質85%程度で保存
5. このフォルダ (`public/images/catering/`) に配置

## 現在の表示について

画像が配置されていない間は、SmartImage コンポーネントが**プレースホルダー**（斜線パターン）を自動表示します。
画像を配置すれば、ページを再読み込みするだけで反映されます。

## 推奨事項

- **ファイルサイズ**: 各画像 300KB以下に圧縮 (Squoosh推奨)
- **カラーモード**: sRGB
- **命名**: 上記のファイル名と完全一致（拡張子も `.jpg` で揃える）
